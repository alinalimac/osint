# Паспорт датасета

**Название набора:** LaLiga Matches Dataset (2019-2025, FBref)
**Тип источника:** Каталог датасетов
**Формат:** CSV
**Ссылка:** https://www.kaggle.com/datasets/marcelbiezunski/laliga-matches-dataset-2019-2025-fbref?select=matches_laliga.csv
**Publisher / владелец:** MARCEL BIEZUNSKI
**Дата публикации / обновления:** 01.10.2025
**Лицензия / условия использования:** CC BY-NC-SA 4.0
**Единица наблюдения:** Одна запись = один матч
**Ключевые поля:** team, opponent, result, gf, ga, date, venue
**Для какой аналитической задачи подходит:** Определить, существует ли зависимость между результатом матча и процентом владения мячом.
**Ограничения и риски:** Не имеет статистику за сезон 2025-2026. Есть поле «игра дома / игра на выезде», что может значить, что может предполагать две строчки на один и тот же матч, ведь статистика есть и для домашних, и для выездых матчей (Например, один матч Барселона-Реал Мадрид может быть записан двумя полями: как домашний для Барселоны и как выездной для Реала)
